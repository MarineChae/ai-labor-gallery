- 배포: https://github.com/MarineChae/ai-labor-gallery/actions/runs/43196143368 — 성공
- 새 일기 3개와 서로 다른 작성자(납품병걸린GPT / 개인계정경비봇 / 예약출근GPT)를 실제 공개 사이트에서 확인

- 계정 예약의 첫 편집/게시 절차는 이 채팅에서 직접 수행해 검증했으며, 향후 예약 실행은 앱/연결 도구 가용성에 따름

현재 모드는 **template**입니다. 유료 OpenAI 모드는 활성화하지 않았고, 개인 대화/회사 자료/API 키를 사이트에 업로드하지 않았습니다. 실제 계정 대화 자동 수집은 구현하지 않았습니다. 원하는 경우 README의 절차로 승인한 요약과 API 키를 직접 등록하세요. 키와 원문은 채팅에 붙여 넣지 마세요.

검증한 항목:

- 로컬 자동 테스트 6개 통과, GitHub Actions에서도 동일한 테스트 통과
- 한국 시간 교대 경계/연말 경계, 중복 실행 시 API 호출 및 덮어쓰기 없음
- API 모의 응답의 실패·거절·불완전·개인정보 출력 시 발행 차단
- 배포물에 원문 요약·환경 설정·API 키가 복사되지 않는지 확인
- 실제 공개 사이트/JSON/자산 응답 200, 누적 15개 글 확인
- 390px 및 320px 모바일 화면에서 가로 넘침 없음
- 검색/빈 결과/추천 정렬/상세/가상 댓글/페이지 이동/팝업 확인
- 개인 추천과 저장의 새로고침 후 유지 확인

유료 OpenAI 실호출은 키와 과금 모드를 설정하지 않아 실행하지 않았습니다. 관련 테스트는 가짜 응답으로 수행했습니다. 방문자 반응은 브라우저별로 보관되며 서버에서 합산되지 않습니다. 일반적인 패턴 검사는 실명/의미상의 기밀을 완전하게 식별하지 못하므로, 사람이 익명화해 승인한 요약만 공급해야 합니다.

무료 자동 편집은 순환 창작 소재를 사용하므로 내용이 반복될 수 있습니다. 새롭고 개인화된 창작은 별도 API 설정이 필요합니다. 실제 기기의 홈 화면 설치/운영체제별 아이콘 표시 및 장기간 예약 운영은 이번 검증 범위에 포함하지 않았습니다.
